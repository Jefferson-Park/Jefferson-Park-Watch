🛡 Crime Batch Upload
Required CSV columns: crime_type,address,zip,incident_date,incident_time,description GTA,12th Ave and 30th St,90018,1/8/26,11:00:00 PM,Suspect took vehicle without permission. Addresses are geocoded using the US Census TIGER/Line geocoder (primary) with Nominatim as fallback. LAPD block addresses like 22** CRENSHAW BL are handled automatically. Duplicate rows (same type + address + date already in the database) are flagged and pre-rejected — use the Include button to override. Use Reject to exclude any READY row before uploading.
